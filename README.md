# PinkClub-Shiroto

FANZAの素人動画に特化した、軽量なアフィリエイト商品サイトです。
[PinkClub-FL](https://github.com/TaniyanR/PinkClub-FL) の現行構成を基盤にしています。

## 対象API

| site | service | floor | 用途 |
| --- | --- | --- | --- |
| FANZA | digital | videoc | 素人動画 |

取得先は素人動画に固定されています。旧DBに別サイト・別フロアの設定値が残っていても商品同期には使用せず、別フロアの商品データが残っていても公開画面には表示しません。

## 特徴

- PHP・MySQL（MariaDB）・JavaScriptで動作
- フレームワーク不使用
- PC・スマートフォン対応
- WordPress風の管理画面
- 商品情報APIだけを使用
- cronによる商品自動更新
- 内蔵アクセス解析
- 商品ランキング
- 公開ページキャッシュ

## 軽量版として外した機能

- 「気分で探す」
- 最近見た作品
- 女優API
- ジャンルAPI
- シリーズAPI
- FloorList API
- 女優プロフィールと女優画像の保存
- 女優プロフィールなどの商品以外の個別詳細ページ
- 商品以外のランキング
- 商品カードの「サンプル画像」ボタン
- 掲載削除依頼機能

商品詳細ページのサンプル画像とサンプル動画は残しています。

## 検索

女優・ジャンル・メーカー・レーベルの名称リンクは、すべて共通の商品検索結果へ移動します。

女優・ジャンル・メーカー・レーベルは、商品APIから保存した名称だけの一覧を表示します。一覧の名称を選ぶと共通の商品検索結果へ移動します。

女優プロフィールは保存しません。商品情報APIに女優名がない素人作品では、商品タイトルの出演者表記を商品との関連情報として`item_actresses`へ保存します。

検索は巨大な`raw_json`全体を走査せず、商品タイトル・商品IDと商品APIから保存した関連名を検索します。

## ランキング

商品ランキングだけを残しています。

- 本日
- 週間
- 月間
- 年間

商品ランキングは30分キャッシュし、古いキャッシュがある場合は表示を維持したまま更新します。

## 内蔵アクセス解析

内蔵アクセス解析はPinkClub-FLと同様に残しています。

- PV・UU
- リファラー
- クリック先
- 検索エンジン
- 検索ワード
- 滞在時間

## セットアップ

1. サーバーへファイル一式をアップロードします。
2. ブラウザで`/public/setup_check.php`を開きます。
3. DBホスト名・ポート・DB名・ユーザー名・パスワードを保存します。
4. 「セットアップを実行する」を押します。
5. `/public/login0718.php`から管理画面へログインします。

初期管理者は`admin`、初期パスワードは`password`です。設置後に管理画面から変更してください。

## API設定

管理画面の「商品情報API設定」で次を保存します。

- APIID
- アフィリエイトID

PinkClub-Shirotoは商品情報API（ItemList）だけを呼び出します。ジャンル・女優などは、商品情報APIの商品データから保存します。

商品情報の取得先は`FANZA / digital / videoc`固定です。FloorList APIや各種マスタAPIは呼び出しません。

## 自動更新

自動更新はcron専用です。公開ページや管理画面へのアクセスでは商品同期を開始しません。

```bash
php /path/to/PinkClub-Shiroto/scripts/auto_import.php
```

推奨cron間隔は10分です。実際の商品取得間隔と取得件数は管理画面から設定できます。

## 固定URL

- 公開トップ：`/public/`
- 管理ログイン：`/public/login0718.php`
- 管理トップ：`/admin/index.php`
- セットアップ確認：`/public/setup_check.php`
- 商品API設定：`/admin/api_items.php`
- 自動設定：`/admin/api_auto.php`
- アクセス解析：`/admin/analytics.php`

## データ保存方針

- 商品は`content_id`を一意キーとしてupsertします。
- APIレスポンスは`items.raw_json`にも保存します。
- 商品に含まれる関連名は、各`item_*`テーブルへ保存します。
- 女優マスタへのプロフィール保存や女優APIによる更新は行いません。
- APIキーやDBパスワードはGitへ保存しません。

## 表示速度

- 不要なAPI同期と個別詳細ページを廃止
- 商品カードのサンプル画像判定・ボタンを廃止
- 公開ページキャッシュ
- 商品ランキングキャッシュ
- 検索用関連テーブル索引
- 画像遅延読み込み
- cron専用の商品同期

## 開発方針

- 既存デザインを維持する
- 不要な全面リファクタリングを行わない
- 作業ブランチとDraft PRを使用する
- 確認前に`main`へマージしない
- 外部画像や動画の利用条件を守る
